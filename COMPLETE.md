## Common Questions

**Q: How long does customization take?**
A: 1-3 hours depending on how detailed your projects are. Content matters more than design.

**Q: Can I change the colors?**
A: Yes! Edit CSS variables in `src/styles/globals.css`. Keep contrast high.

**Q: Do I need to include all sections?**
A: Yes, these 6 sections cover everything a recruiter needs to know in 60 seconds.

**Q: How many projects should I include?**
A: 2-4 strong projects beat 5 weak ones. Quality > Quantity.

**Q: Can I add animations?**
A: Yes, but current subtle hover effects are intentional. Avoid heavy animations—they distract from content.

**Q: Should I include old projects?**
A: Only if they're impressive or show clear growth. Focus on your best work.

## Deployment Options

### **Vercel** (Recommended)
- Instant deployment
- Free tier
- Automatic SSL
- Environment variables supported
```bash

```

### **GitHub Pages**
- Free
- Simple setup
- No backend needed
```bash

```

```
3. Done!
```

### **Traditional Hosting**
- Any static host works
- FTP/SFTP upload
